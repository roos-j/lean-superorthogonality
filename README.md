## Formalization of superorthogonality
[![Lean](https://github.com/roos-j/lean-superorthogonality/actions/workflows/lean.yml/badge.svg?branch=palomar-cdw)](https://github.com/roos-j/lean-superorthogonality/actions/workflows/lean.yml)

This repository contains formalizations of the following main results:

* An $`L^{2r}`$ square-function estimate for type IV superorthogonality: Theorem 1 from Gressman-Pierce-Roos-Yung [2]

* An $`L^4`$ square-function estimate for superorthogonal families: Theorem 1.1 from Cushman-Demeter-Wu [1]

* A sharp $`L^4`$ square-function estimate for the cone: Theorem 1.4 from Cushman-Demeter-Wu [1]
This estimate sharpens the cone square-function estimate of Guth-Wang-Zhang [3].

The theorem statements are in [`Theorems.lean`](LeanSuperorthogonality/Theorems.lean) and supporting definitions in 
[`Defs.lean`](LeanSuperorthogonality/Defs.lean).

### References

[1] A. Cushman, C. Demeter, S. Wu. [Diameter-free reverse inequalities and superorthogonality](https://arxiv.org/abs/2609.13105v1), arXiv:2609.13105v1, 2026.

[2] P. T. Gressman, L. B. Pierce, J. Roos, and P.-L. Yung. [A new type of superorthogonality.](https://arxiv.org/abs/2212.08956) *Proc. Amer. Math. Soc.* 152, 665-675, 2024

[3] L. Guth, H. Wang, and R. Zhang. A sharp square function estimate for the cone in $\mathbb{R}^3$. Ann. of Math. 192, 551-581, 2020.

### Palomar registrations

Palomar is a public, searchable registry of Lean formalizations whose proofs have been machine-checked. Each entry points to an immutable version of a public repository and records the exact formal statement that was checked, its dependencies, the result of the proof check, and the findings of a documented editorial review.

* The Type IV superorthogonality formalization is registered in Palomar as [PALOMAR-2026-08-31-000015](https://palomar-registry.org/entry?id=PALOMAR-2026-08-31-000015&version=1).

### Build instructions

To build and verify the formalization locally follow these steps:

* Install Lean 4 following instructions [here](https://lean-lang.org/install/).

* Clone this repository using

  `git clone https://github.com/roos-j/lean-superorthogonality`

* Run `lake build`
from the terminal in VSCode.

The GPRY Palomar submission files, including `Challenge.lean`, `Solution.lean`, `comparator.json`, `formalization.yaml`, and the Comparator workflow, are maintained on the [`palomar-gpry` branch](https://github.com/roos-j/lean-superorthogonality/tree/palomar-gpry). On that branch, the formalization can also be checked with [Lean Comparator](https://github.com/leanprover/comparator#readme). `Challenge.lean` intentionally contains a `sorry` for this purpose, while `Solution.lean` supplies the proof.

### CDW Palomar submission (palomar-cdw only)

This branch prepares Theorems 1.1 and 1.4 of Cushman-Demeter-Wu [1].
The submission files are isolated from `master`. [Challenge.lean](Challenge.lean)
imports only Mathlib and reproduces the public declarations and their necessary
definitions. [Solution.lean](Solution.lean) imports the existing proofs.
These two generated submission files are exceptions to the Auto-folder convention.

`Superorthogonal.CDW.sqfct_estimate_of_superorthogonal`

For any measure space, natural number $N$ and ordered-superorthogonal
family of complex-valued L4 functions indexed by $0\le j<N$,
$$
\left\|\sum_j f_j\right\|_{L^4(\mu)}
\le 33(1+\log N)^2\|S_f\|_{L^4(\mu)}.
$$
The empty family is included.

`Superorthogonal.CDW.cone_sqfct_estimate`

For every natural number $N$ and family of complex-valued Schwartz
functions on Euclidean three-space whose Fourier supports lie in the
corresponding conic sectors,
$$
\left\|\sum_j f_j\right\|_{L^4}
\le 46(1+\log N)^{1/4}\|S_f\|_{L^4}.
$$
The norms use Lebesgue measure, and the cases $N=0,1$ are included.

Here ordered superorthogonality means that, for each increasing quadruple,
the two nonalternating quartic products have zero integral; measurability and
integrability are explicit. The square function is the square root of the sum
of squared absolute values. The sectors are the closed sets parametrized by
$(r,rt,rt^2+u)$ with $1\le r\le2$, $j/N\le t\le(j+1)/N$ and $|u|\le N^{-2}$.

Only the upper estimates are submitted. The sharpness lower bound, arbitrary
angular partitions, the parabola theorem and GPRY results are excluded. The
metadata records AI involvement and does not claim an independent human review
of the complete generated proofs.

Run `lake build` locally. The Palomar mechanical-preflight workflow runs on a
push to `palomar-cdw`, using the pinned official verification pipeline with
its Linux sandbox and independent kernels. Local builds and the advisory quick
comparator do not replace that verification. Preparation is not submission:
registration requires a public immutable commit and the submitter's authorization
declaration through Palomar.
