# Agent instructions

Agents working in this repository must read and follow the autoformalize skill at
[.codex/skills/autoformalize/SKILL.md](.codex/skills/autoformalize/SKILL.md) when it is
present. If it is absent, use the user-installed copy at
`~/.codex/skills/autoformalize/SKILL.md` (or `$CODEX_HOME/skills/autoformalize/SKILL.md`
when `CODEX_HOME` is configured).

Agents must also read the applicable local instructions in [automation/](automation/),
beginning with [automation/instructions.md](automation/instructions.md). Those local
instructions supersede conflicting guidance in the skill.

The user's current explicit instructions take precedence over both this file and the
skill.
